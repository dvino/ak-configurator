## Contract and review

The authoritative source for the wire and firmware-derived values is [B02-CONTRACT-AUDIT.json](B02-CONTRACT-AUDIT.json). The record is 24 bytes with header `51 53 03 11 ff`; CRC-16/CCITT covers bytes 0–21 and is stored little-endian in bytes 22–23. QSID 23 is a little-endian `u16` at offset 20. Firmware C blank defaults set QSID 22 at byte 17 to 1; the official Python v3 default vector sets it to 0. V1 migration preserves its byte-17 value (zero for v1), and v2 migration preserves its existing value. Image marker 300 is verified for all ten linked IHX/map profiles.
