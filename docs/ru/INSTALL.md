# Установка и запуск

AK Configurator `0.1.0-alpha.1` готовится для Windows x86_64 и ARM64. Выпуск не опубликован, публичной загрузки нет. Основной способ установки — нативный графический установщик для текущего пользователя; переносимый ZIP служит альтернативой. Исполняемый файл x86_64 прошёл изолированные проверки GUI и обмена служебной информацией MCP. Неподписанный графический установщик прошёл изолированные установку, переустановку той же версии и удаление. Подписанный установщик и финальный пакет пока не готовы. Упаковка и CI для ARM64 настроены, но запуск ARM64 не проверялся. Не используйте вместо этого кандидата прежние платформенные артефакты.

## Пакет-кандидат

Для локальной передачи предназначен переносимый архив x86_64 `ak-configurator-0.1.0-alpha.1-windows-x86_64.zip`; это не выпуск на GitHub. Подписанный установщик и архив, их контрольные суммы и загрузка ещё ожидаются. Нынешний неподписанный `ak-configurator-0.1.0-alpha.1-windows-x86_64-setup.exe` — изолированный тестовый артефакт, а не установщик выпуска. Планируемое имя ARM64-установщика: `ak-configurator-0.1.0-alpha.1-windows-arm64-setup.exe`; его запуск не проверялся. Smoke x86_64 не охватывал внешний вид мастера, обновление предыдущей версии, сохранность настоящих настроек или работу MCP после установки. При передаче финальных файлов до распаковки или запуска проверьте внешнюю SHA256 и внутренний `SHA256SUMS` архива. Если файл контрольной суммы отсутствует или значение не совпадает, остановитесь.

Для финального подписанного установщика x86_64 запустите `ak-configurator-0.1.0-alpha.1-windows-x86_64-setup.exe` из Explorer и выполните шаги графической установки для текущего пользователя. Команда PowerShell для этого не нужна. Изолированная проверка охватила установку, самопроверку приложения, переустановку тем же установщиком, удаление, регистрацию в меню Пуск и списке приложений/удаления, а также проверку контрольного файла. Переход с предыдущей версии не проверялся.

Проверка и распаковка в PowerShell:

```powershell
$ErrorActionPreference = 'Stop'
$archive = 'ak-configurator-0.1.0-alpha.1-windows-x86_64.zip'
$expected = ((Get-Content -LiteralPath "$archive.sha256") -split '\s+', 2)[0].ToLowerInvariant()
$hashOutput = certutil -hashfile $archive SHA256
$actual = ($hashOutput | Where-Object { $_ -match '^[0-9a-fA-F]{64}$' } | Select-Object -First 1).ToLowerInvariant()
if ($actual -ne $expected) { throw 'Archive SHA256 mismatch' }
Expand-Archive -LiteralPath $archive -DestinationPath .
Set-Location ($archive -replace '\.zip$', '')
Get-Content -LiteralPath SHA256SUMS | ForEach-Object {
    $expectedHash, $relativeFile = $_ -split '  ', 2
    $hashOutput = certutil -hashfile $relativeFile SHA256
    $actualHash = ($hashOutput | Where-Object { $_ -match '^[0-9a-fA-F]{64}$' } | Select-Object -First 1).ToLowerInvariant()
    if ($actualHash -ne $expectedHash.ToLowerInvariant()) { throw "SHA256 mismatch: $relativeFile" }
}
```

После проверки запустите переносимое приложение командой `Start-Process .\ak-configurator.exe`. Для альтернативного ZIP пока нет финальной контрольной суммы или результата установки. Политика PowerShell на этом компьютере указывает `LocalMachine=AllSigned`; остальные области не заданы. Политику не меняли и проверку подписи не обходили. Нативный Inno Setup не требует PowerShell; необязательный прежний `.ps1`-установщик может быть заблокирован действующей политикой. Для запуска программы Python и дополнительные Python-пакеты не нужны; скрипты упаковки используют стандартную библиотеку Python.

## Сборка из исходников

Нужны Windows x86_64, Rust, инструменты сборки C++ MSVC и Windows SDK. Из корня репозитория выполните:

```powershell
cargo build --release --locked --features mcp
.\target\release\ak-configurator.exe --self-check --output .\target\release\self-check.json
```

Оптимизированный исполняемый файл с MCP прошёл офлайн self-check каталога Beta5 и десяти профилей. Он также прошёл smoke-проверку нативного GUI с новой изолированной конфигурацией и запрещённым live HID, а production MCP STDIO/SDK-проверки не запрашивали hardware-инструменты. Эти результаты не включают установку архива. Сам self-check не открывает GUI, не ищет HID-устройства, не обращается к сети и не выполняет операций с устройством. Отдельный исполняемый файл не является полным пакетом: в нём должны быть проверенные публичные файлы прошивки и остальные заявленные материалы.

## Текущие ограничения

Этот этап охватывает упаковку Windows x86_64 и ARM64. Linux и macOS не входят в текущую область; требование шести целей остаётся открытым. Проверки исполнения есть для файла x86_64; фактический запуск ARM64, итоговая подпись, публикация и установка финального пакета не выполнены. Сборки кандидата включают MCP для чтения; сервер запускается только с явными аргументами MCP. Обычная сборка Cargo не включает эту возможность. MCP показывает метаданные и готовит локальный план установки, но не записывает настройки, не выполняет восстановление или прошивку. Физическое поведение клавиатуры не квалифицировано. При проверке установки не разблокируйте клавиатуру, не сбрасывайте её, не переводите в загрузчик и не выполняйте запись.
