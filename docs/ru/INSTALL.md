# Установка и запуск

AK Configurator `0.1.0-alpha.1` предназначен для Windows x86_64 и ARM64. Загрузите GUI-установщик для текущего пользователя или переносимый ZIP со [страницы выпуска на GitHub](https://github.com/dvino/ak-configurator/releases/tag/v0.1.0-alpha.1). Установщик — основной способ; ZIP — альтернативный. Windows-пакеты подписаны локальным сертификатом разработки, а не сертификатом публичного центра сертификации. В зависимости от компьютера Windows может показывать предупреждения об издателе или доверии; выпуск не гарантирует системное доверие или статус SmartScreen. Пакеты для не-Windows платформ, если они указаны, экспериментальные и не квалифицированы. Приёмка нативной macOS не входит в область этой альфы. Результаты проверок и ограничения описаны в [состоянии проекта](STATUS.md).

## Пакет Windows

Выберите файлы для архитектуры Windows в списке материалов выпуска:

| Архитектура | GUI-установщик | Переносимый архив |
|---|---|---|
| x86_64 | `ak-configurator-0.1.0-alpha.1-windows-x86_64-setup.exe` | `ak-configurator-0.1.0-alpha.1-windows-x86_64.zip` |
| ARM64 | `ak-configurator-0.1.0-alpha.1-windows-arm64-setup.exe` | `ak-configurator-0.1.0-alpha.1-windows-arm64.zip` |

Загрузите соответствующий файл `.sha256` и проверьте внешнюю SHA256 до распаковки или запуска. ZIP распаковывайте только после успешной внешней проверки; затем сверьте внутренний `SHA256SUMS` до запуска любого файла. Если контрольная сумма отсутствует или отличается, остановитесь. Примеры ниже используют x86_64; для ARM64 выберите соответствующие имена файлов.

Запустите соответствующий `*-setup.exe` из Проводника и выполните шаги установки для текущего пользователя. Пакет ARM64 содержит нативные ARM64-приложение и аудиопомощник; оболочка Inno Setup использует эмуляцию x64 в Windows 11 ARM. Доверие Windows к локальному сертификату определяется настройками ОС. Проверенное поведение установщика и оставшиеся ограничения указаны в [состоянии проекта](STATUS.md).

Проверка и распаковка в PowerShell:

```powershell
$ErrorActionPreference = 'Stop'
$archive = 'ak-configurator-0.1.0-alpha.1-windows-x86_64.zip'
$expected = ((Get-Content -LiteralPath "$archive.sha256") -split '\s+', 2)[0].ToLowerInvariant()
$hashOutput = certutil -hashfile $archive SHA256
$actual = ($hashOutput | Where-Object { $_ -match '^[0-9a-fA-F]{64}$' } | Select-Object -First 1).ToLowerInvariant()
if ($actual -ne $expected) { throw 'Archive SHA256 mismatch' }
Expand-Archive -LiteralPath $archive -DestinationPath .
Set-Location ($archive -replace '\.zip$', '')
Get-Content -LiteralPath SHA256SUMS | ForEach-Object {
    $expectedHash, $relativeFile = $_ -split '  ', 2
    $hashOutput = certutil -hashfile $relativeFile SHA256
    $actualHash = ($hashOutput | Where-Object { $_ -match '^[0-9a-fA-F]{64}$' } | Select-Object -First 1).ToLowerInvariant()
    if ($actualHash -ne $expectedHash.ToLowerInvariant()) { throw "SHA256 mismatch: $relativeFile" }
}
```

После проверки запустите переносимое приложение командой `Start-Process .\ak-configurator.exe`. Необязательный прежний `.ps1`-установщик подчиняется политике PowerShell на этом ПК. Графический установщик работает нативно. Для запуска приложения Python не нужен; скрипты упаковки используют Python 3.11 или новее и его стандартную библиотеку. Результаты проверок указаны в [состоянии проекта](STATUS.md).

## Сборка из исходников

Нужны Windows x86_64, Rust, инструменты сборки C++ MSVC и Windows SDK. Из корня репозитория выполните:

```powershell
cargo build --release --locked --features mcp
.\target\release\ak-configurator.exe --self-check
```

Сам self-check не открывает GUI, не ищет HID-устройства, не обращается к сети и не выполняет операций с устройством. Отдельный исполняемый файл не является полным пакетом: в нём должны быть проверенные публичные файлы прошивки и остальные заявленные материалы.

## Текущие ограничения

Эта альфа охватывает упаковку Windows x86_64 и ARM64. Квалификация Linux ещё не завершена; приёмка нативной версии для macOS не входит в утверждённую область. Ни одна из этих платформ не прошла квалификацию. Результаты проверки интерактивного использования ARM64 и установщика указаны в [состоянии проекта](STATUS.md). Сборки кандидата включают MCP для чтения; сервер запускается только с явными аргументами MCP. Обычная сборка Cargo не включает эту возможность. MCP показывает метаданные и готовит локальный план установки, но не записывает настройки, не выполняет восстановление или прошивку. Физическое поведение клавиатуры не квалифицировано. Операций с физической клавиатурой не проводили. При проверке установки не разблокируйте клавиатуру, не сбрасывайте её, не переводите в загрузчик и не выполняйте запись.
