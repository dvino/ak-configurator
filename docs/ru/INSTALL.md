# Установка и разработка

Готовых пакетов AK Configurator пока нет. Скачанный Entropy не считается
проверенным выпуском для AK820. Состояние исходников и ограничения проверки
приведены в [статусе](STATUS.md).

## Сборка импортированных исходников

Установить инструментарий Rust и зависимости ОС, описанные в
[BUILD.md](../../BUILD.md). В корне репозитория:

```sh
cargo build --release
```

Команда собирает импортированное приложение Entropy, пока с именем `entropy`.
Она не подтверждает поддержку AK820. При переносе эта команда не выполнялась.
Запущенное приложение может искать устройства; сама сборка USB не открывает.

## Будущие пакеты

Для каждого выпуска AK Configurator инструкции RU/EN должны объяснять выбор
ОС и архитектуры, скачивание, проверку SHA256, распаковку или установку и запуск.
Целевые системы — Windows/Linux x86_64 и macOS arm64/x86_64. Точные имена файлов
и команды добавляются после появления настоящих пакетов.

Установка и восстановление существующей прошивки описаны в
[инструкции AK820](https://github.com/dvino/ak820/blob/dev/docs/ru/INSTALL.md).
