# Руководство для десктопной версии

Эта альфа-версия поддерживает проводную AK820 только с проверенной полной постоянной прошивкой v0.6.0-alpha.3. При подключении приложение проверяет совместимость прошивки. Неизвестная, пользовательская, пробная или несовпадающая прошивка отклоняется.

## Офлайн-профили beta

Запуск `ak-configurator --demo-ak820` открывает встроенные примеры без доступа
к USB. Выберите профиль в окне **«Локальный проект примера»**. Подробный
каталог остаётся в меню **«Раскладка → Профили прошивки beta.1»**. Правки каждого профиля сохраняются при переключении в пределах
одной сессии. Примеры не являются настройками, прочитанными с клавиатуры.
Кнопка **«Сохранить проект»** в окне локального проекта записывает текущий
профиль в `.ak820project.json`. **«Открыть проект»** проверяет весь файл
до замены его профиля. До закрытия приложения сохраните каждый профиль
отдельно. **«Отменить импорт проекта»** возвращает пример, активный
до последнего успешного импорта, в том числе при замене того же профиля. Неверный черновик модуля нужно исправить или отменить до сохранения.
Эти файлы сохраняют правки примеров; они не восстанавливают настройки
клавиатуры или OEM-прошивку.

Список назначений учитывает профиль и источник действия. Три профиля schema03
имеют отдельную офлайн-панель: восемь записей Tap Dance, восемь записей
Key Overrides либо активные ID настроек QMK. Закрытая панель открывается
кнопкой **«Настройки модулей»** в окне локального проекта. Неверное значение не заменяет
последние корректные настройки. В остальных профилях зарезервированное
хранилище расширений недоступно. Dynamic Macro и режимы сессии остаются
временными функциями прошивки; назначение клавиши не эмулирует их физическую
работу на компьютере.

Выбор офлайн-профиля не изменяет подключённую клавиатуру и не включает
установку beta-прошивки. Подключение устройства пока принимает только точный
образ alpha.3, описанный ниже.

## Перед редактированием

Подключите клавиатуру и прочитайте её текущие настройки. Редактор поддерживает 6 слоёв, 83 клавиши и один энкодер с обоими направлениями вращения и обычным нажатием в матрице. Также доступны до 16 макросов общим объёмом 8192 байта, текст ASCII и коды макросов Vial 1–7; до 8 двухклавишных Combo с интервалом 40 мс; режимы RGB Off (выключено, 0), Direct (прямое управление, 1), Solid (постоянный цвет, 2), Breathing (дыхание, 6), Cycle all (смена цветов, 13), Cycle left/right (смена цветов слева направо и справа налево, 14) и Reactive (реакция на нажатия, 31) для 82 светодиодов; максимальная яркость — 160. Режим Direct можно выбрать, но в этой альфа-версии пока нет редактора палитры отдельных светодиодов. Палитра хранится во временной памяти устройства и не считывается обратно.

После сохранения приложение проверяет значение, прочитанное обратно с клавиатуры. Если запись или проверка завершилась ошибкой, прекратите редактирование и явно выберите **«Прочитать настройки снова»**, прежде чем продолжать.

## Разблокировка макросов

Чтобы разблокировать редактирование макросов, выберите **Unlock** в приложении, затем удерживайте Esc и левый Ctrl три секунды до завершения разблокировки. Это действие выполняется явно пользователем.

## Поддерживаемые действия клавиш

Прошивка распознаёт коды Mod-Tap и Layer-Tap с интервалом 200 мс, простое переключение слоя TT, One-Shot Modifier только для модификаторов, автоматическое включение слоя 3 при активных слоях 1 и 2, временный Default Layer, Caps Word, Key Repeat, Alternate Key Repeat, NKRO и Space Cadet. Наличие кода описывает поведение прошивки; здесь можно настроить только действия, для которых есть элемент управления в редакторе.

Постоянное назначение базового слоя, Tap Dance, действия мыши, произвольные переопределения кодов клавиш и общие настройки QMK не входят в эту альфа-версию. Наличие действия в унаследованном редакторе Entropy не означает, что прошивка его поддерживает.

## Резервные копии и операции с прошивкой

Действие **«Сохранить проект»** записывает `.ak820project.json` с правками
офлайн-примера. Этот файл проекта отделён от локального каталога копий:
кнопка в строке состояния открывает только чтение каталога. Она не создаёт
копии, историю или экспорт и не выполняет восстановление. Ввод-вывод каталога
пока поддерживается только в Linux.

Существующий экспорт `.entlayout` — частичный снимок редактора. Это не полная
копия настроек, архив восстановления или копия штатной прошивки OEM. Импорт
для AK820 пока недоступен: ещё не реализованы проверки совместимости и
обязательные проверки предварительной копии. Не используйте `.entlayout` для
восстановления клавиатуры.

Эта альфа-версия не устанавливает прошивку, не восстанавливает OEM-прошивку и
не запускает системный помощник LED. Кнопка просмотра каталога не выполняет
эти операции. Поддержка браузера запланирована после того, как десктопная
версия будет в разумной степени готова.
