# Состояние проекта

Обновлено 24.10.2026. Основа репозитория — коммит Entropy
`5b222b5d6349fb351f53b36c66169095b3039fc1` с историей Git и лицензиями.
ТЗ и план перенесены из плановой ветки AK820 и исправлены для отдельного
репозитория конфигуратора.

## Исходники, сборки и устройство

Приложение на Rust импортировано из upstream. Имя пакета Cargo, исполняемого
файла, оформление и поведение оборудования пока относятся к Entropy: поддержка
AK820 ещё не добавлена. Это не проверенный клиент для AK820. При переносе
не собирались, не выпускались и не публиковались бинарники, установщики или
сайт AK Configurator. USB-команды и проверки устройства не выполнялись.

В Entropy есть нативная настройка и часть кода для Wasm, но исследование
исходников не подтвердило рабочий браузерный WebHID. Сначала адаптируется
нативный клиент; общая браузерная версия разрабатывается параллельно.
Выбор основы не подтверждает возможность прошивки из браузера.

## Репозиторий и ветки

В `main` находятся общие проверенные исходники. Нативная разработка идёт
в `desktop-dev`, подготовка нативного выпуска — в `desktop`, браузерная
разработка — в `web-dev`. Эти ветки теперь относятся к `dvino/ak-configurator`,
а не к `dvino/ak820`. Общие изменения сливаются между ветками разработки
и проверяются для обеих версий. Совместимость связывается с точными версиями
прошивки и конфигуратора в двух репозиториях.

Импортированные workflows относятся к сборке Entropy. Это ещё не готовая
проверка AK820 или совместного выпуска двух проектов. Импортированный workflow
выпуска ограничен upstream-репозиторием. Теги Entropy не копируются
как релизы AK Configurator.

Оставшаяся работа и условия выпуска описаны в [плане](PLAN.md).
Проверки документов, независимое ревью и результаты переноса —
в [REVIEW.md](REVIEW.md).
