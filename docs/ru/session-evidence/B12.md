## Прогресс установщика и подписи

Нативный Inno Setup 7.1.1 установлен. Первый неподписанный установщик заменён после исправления изоляции группы в меню Пуск. Пересобранный `ak-configurator-0.1.0-alpha.1-windows-x86_64-setup.exe` прошёл описанную выше изолированную проверку цикла установки. Основной путь — нативный GUI-установщик для текущего пользователя; переносимый ZIP остаётся альтернативой. PowerShell-команда не нужна. Планируемое имя установщика ARM64 — `ak-configurator-0.1.0-alpha.1-windows-arm64-setup.exe`; его запуск не проверяли. Необязательный прежний `.ps1` по-прежнему подчиняется действующей политике выполнения. Политику не меняли и проверку подписи не обходили.

Native CMS-проверки подписи прошли для положительного файла и отрицательного случая с изменённым содержимым. Проверки подписи и временной метки исполняемого файла и PowerShell сохранили проверенные байты; цепочка временной метки корректна. Полная проверка `SignTool` завершилась с кодом 1: локальный корневой сертификат не доверен, подтверждённых файлов — 0. PowerShell вернул `UnknownError`. В CI заданы зашифрованные секреты подписи и открытые переменные с закреплённым thumbprint сертификата; значения секретов здесь не записаны. Доверие Root/Publisher для текущего пользователя ещё не настроено. В CI на hosted runner используется отдельный временный магазин Root в LocalMachine; он не задаёт доверие на компьютере пользователя. Финального подписанного установщика, успешного signing CI, установки финального пакета и проверки установленного MCP пока нет.

Настроен CI/package-путь ARM64 с нативным payload приложения и x64 загрузчиком Inno Setup под эмуляцией Windows ARM. Фактический запуск на ARM64 не выполнялся; это подтверждает только конфигурацию пакета и workflow.

До замены проверили прежнюю установку приложения для пользователя: 67 файлов, 65 контрольных сумм, ноль несовпадений и ноль reparse points. Приватную копию и ярлык проверили; исходная установка не менялась. Независимые reviewers `windows_delivery_review` и `delivery_native_followup_review` не обнаружили блокирующих замечаний в своих областях. Ограничения остаются: CMS unsigned pair и native verification assertion не пересчитаны независимо; проверялась переустановка той же версии, не обновление с предыдущей.

## Предварительная проверка подписи 41744467881

[Запуск 41744467881](https://github.com/dvino/ak-configurator/actions/runs/41744467881), коммит `54ffc289b9a2d4720f847440a21aedc21754050c`, завершился ошибкой до полной сборочной матрицы. В этом коммите издатель импортировался в CurrentUser TrustedPublisher. Матрица пропущена, артефактов нет; см. [сохранённые сведения](../../session-evidence/B12-checks/ci-41744467881.json). Это локализует операцию, но не устанавливает причину на уровне политики или API.

Продолжение явно выбирает LocalMachine TrustedPublisher вместе с LocalMachine Root на изолированном GitHub runner с правами администратора; закрытый ключ остаётся в CurrentUser My. Доверие издателю временно распространяется на всех пользователей одноразовой ВМ. Проверка существующих записей, точной закреплённой идентичности, владения и очистка используют те же выбранные хранилища. Автоматического запасного пути или изменения политики нет. Этот CI-путь импорта и очистки на компьютере пользователя не запускался. Microsoft описывает [область машинных и пользовательских хранилищ](https://learn.microsoft.com/en-us/windows-hardware/drivers/install/local-machine-and-current-user-certificate-stores) и [машинное хранилище издателей](https://learn.microsoft.com/en-us/windows-hardware/drivers/install/using-certmgr-to-install-test-certificates-on-a-test-computer); это не утверждение о применении политики драйверов к приложению. Все 13 офлайн-проверок прошли за 0.616 s, независимое ревью кода не нашло блокирующих замечаний. Успешная подпись ARM ещё требует следующего нативного CI.

## Ожидающие проверки и ограничения

- Подготовить финальные подписанные Windows x86_64 архив и GUI setup, проверить внутренние/внешние checksum и signing CI. Фактический размер и SHA256 записать вне документов, включаемых в архив, чтобы не создавать самоссылочный хеш.
- Настроить разрешённое доверие Root/Publisher только для текущего пользователя, затем проверить подписанный setup и установленное приложение/MCP. Финального подписанного пакета, результата настройки доверия и signing CI пока нет. Не заявлять идентичность публичного CA или автоматическое доверие на других ПК.
- Политика PowerShell на этом компьютере указывает `LocalMachine=AllSigned`; остальные области не заданы. Глобальную политику не меняли и проверку подписи не обходили. Нативный Inno Setup не требует PowerShell; необязательный прежний `.ps1` может быть заблокирован политикой.
- Десять ignored-тестов остаются не квалифицированы; прежние результаты B11/C04 не заменяют текущие проверки.
- Завершить итоговое независимое ревью интегрированных исходников, документации и evidence. B12 не принимается до прохождения подписания, пакета, установки и ревью.

В инвентаризации Ubuntu 6.18.54 x86_64 WSL есть Python и pkg-config, но нет Cargo/rustc, Node, Cargo-зависимостей и необходимых нативных пакетов. VHDX Debian отсутствует. Это сведения об окружении, а не квалификация Linux. Нативная macOS явно исключена из текущего этапа и остаётся непроверенной.

Операций с физической клавиатурой не выполняли. Проверки оборудования, включая совместную прошивку на месте, относятся к отдельному более позднему этапу с отдельным разрешением. Кандидат не разрешает запись сохранённых настроек, выполнение восстановления или MCP-прошивку.
