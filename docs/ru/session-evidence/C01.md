## Текущий статус

**Ограниченная офлайн-область исходника и evidence C01 принята 2026-11-03** независимым reviewer `c01_exact_review`. Reviewer независимо проверил хеши всех 60 source files и inventory report, перепроверил шесть identity-полей private fixture и повторно выполнил три итоговых целевых теста; прочие результаты C(all), lint, build и STDIO приняты как сообщённые и не перезапускались. Приёмка охватывает exact Beta5 bootstrap/admission и интеграцию packed metadata. Она не квалифицирует установленный image, live MCP/device behavior или готовность выпуска. Ограниченный cfg(test)-only seam использует существующий helper-process/registry code; `c01_review` принял его scope условно на runtime checks. Поведение с именованным OS lease или live HID не заявляется. Записей в hardware не выполнялось.

Официальный контракт FD00/FD01 v1 привязан к firmware commit `dfd0770f9ef64bf5c7ab6d40e9f9e7b4354cd2cd` и source-verified. Для C01 повторно сверены те же три входа, что в B01, bundle/matrix, IHX map и packer blob hashes. Расследование связало mismatch предыдущей fixture с B01 CLI defaults: они выбирали manifest schema `0x082002`, тогда как settings identity Beta5 catalog — `0x082003`. Dedicated test завершился `no reviewed capability entry`; эта fixture, собранная CLI, не подтверждает корректную упаковку Beta5 image. Mismatch устранён для новой fixture по official installer recipe из `tools/installer/ak820.py`, blob `b4a70639a0832dd652d250177c0f0ca9148586da` (строки 500–527): выполнить `migrate_vial_nvm(nvm, packer.BUILD_ID, target_build_id=context.nvm_schema)`, затем `pack(..., False, target_build_id=context.nvm_schema)` и проверить, что payload использует ту же schema. Новая постоянная private fixture использовала этот packer blob и extension blob `3951fad9e4914bca3879234845d6cdae57a43fc1`, проверенные входы B01 и верифицированные public assets. Packer verification прошёл; размер package 51,136 bytes, SHA256 `037c394278fa1ce3352aaa5828292b63022a5804385e06d0363ead117efa73bf`, manifest schema `0x082003`; CODE SHA256 прежний `cd11665942abb5dc01b3bdce0c73b1520c6e106a9cb8d754b891b12171e4f784`. Предыдущая CLI fixture не квалифицирует Beta5 packaging. Unknown-identity и schema checks не ослаблялись. Доказательство B01 CODE identity остаётся валидным. Private paths и bytes fixture не публикуются.

Для provenance команда `git fetch --no-tags origin dfd0770f9ef64bf5c7ab6d40e9f9e7b4354cd2cd` выполнялась в исходном firmware repository. Она изменила object store и `FETCH_HEAD`; tracked files не редактировались. Поэтому Git metadata не оставалась полностью неизменной. Повторный fetch из этого repository не планируется.
