Исторический pre-LeaseBusy snapshot `beta5` прошёл 5/1935 filtered за 1,76 s, включая identity/capability, отказ restore, QS v3 capture, stale RGB без packets и write guard всех профилей; он также не является проверкой текущей итоговой версии.

Для будущей catalog-limit семантики V3 metadata сверяет exact digests embedded source catalog. Published version assets должны оставаться byte-pinned: изменение может приводить к явному отказу старого archive, а не к незаметной перепривязке backup identity. Пины Beta4.1 и Beta5 версионированы. Совместимость с недоступными будущими каталогами не заявляется. Эти pre-LeaseBusy snapshots и compile checks не подтверждают runtime или поведение устройства.

## Объём и ограничения

B04 распределяет read-only работу по worker для decoder, settings model, HID/session connection и worker error handling. Capture и archive metadata затрагивают три файла. Общие HID capture owner и session сохранены. Отсутствующие optional значения selected target и trusted receipt явно остаются `None`; они не выводятся предположительно.

Windows path regression закрыта на проверенном исходнике. Финальный rebuilt-source тест `contended_lease_roundtrips_to_capture_without_opening_hid` прошёл от реальной OS contention через production in-process serialized strict IPC и shared open classifier до GUI capture availability. Физический HID не открывался; это не полный subprocess run. Финальные backup, post-open failure, lifecycle, Beta5-filter, settings-backup, HID-backup и connection-filter tests прошли; результаты приведены выше. При LeaseBusy выбор устройства намеренно возвращает `OperationBusy`. Более ранние boundary tests остаются историческими результатами отдельных snapshots. Reviewers `b04_lease_review` и `b04_final_review` не выявили blocking source issue; `b04_final_review` принял offline scope 2026-11-03 на основе статического review и сообщённых результатов без rerun. Evidence не подтверждает полный Beta5 GUI fixture, авторизацию ROM, поведение физического устройства или готовность выпуска. B03 принята отдельно; офлайн-область UI B05 принята отдельно.
