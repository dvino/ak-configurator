# C04 — immutable read-only prepare

English original: [C04 evidence](../../session-evidence/C04.md).

## Состояние

**Независимый reviewer `c04_final_review` принял ограниченную offline Windows C04 область (2026-11-03).** Это не приёмка всей read-only MCP и не квалификация других платформ, GUI/device behavior, ignored tests или source-to-binary linkage. Адаптер добавляет `ak820_prepare` как восьмой tool MCP. Он использует native installer prepare builder и private archive C03. Реализована только фиксированная install preview; settings-restore plans не поддерживаются. План использует закрытый versioned canonical формат с digest, точными source/target/catalog/backup bindings и сроком действия 15 минут. `settings_writes_authorized` остаётся false. Packed image payload не возвращается. Source observations устройства и bootstrap admission — разные проверки: локальная подготовка не устанавливает live identity или admission.

## Работа операции и ограничения

Prepare доступен через существующий CLI `--mcp-access=read-only`, поскольку выполняет ограниченную локальную работу с artifacts без device mutation. Новый scope flag не добавлялся. Асинхронный запрос при принятии возвращает operation ID; существующие actions `status` и `cancel` инструмента `ak820_operation` показывают состояние и terminal result. Для queued operation `lease_held` равен `null` (неизвестно), а не false. Prepare использует существующего engine owner при его наличии и не получает HID lease при старте worker. Процесс ограничивает число retained operations до 32 на время своего существования. Если принятый ID потерян до получения transport receipt, восстановить его нельзя: actions list/get нет.

Builder строго разбирает canonical closed plans, отклоняет duplicate/unknown input fields, изменённые или устаревшие bindings, expired plans и недопустимые admission. Отзыв выбранного release проверяется через read-only blocked-pins path без создания, миграции или записи pin state. Проверка loader source ограничена. Реализация не создаёт approval, не предоставляет execute и не открывает HID writer. Read-only input guard описан отдельно в [evidence C04 input guard](C04-INPUT-GUARD.md).

Переиспользуется native B11 install preparation. Beta.3 по-прежнему запрещена для production admission. Beta.4 в pure model — это только offline coverage, она не квалифицирует beta.4 для live MCP. Sticky withdrawal blocks сохраняются. Read-only source-observation check ограниченно проверяет loader, но не подтверждает bootstrap admission. Владение ancestor каталогами persisted release-observation file и их owner не удалось доказать. Сохраняются лимиты C02 store: 1 MiB на plan, 16 MiB на backup, 100 artifacts без automatic eviction. Windows сообщает `DirectoryFlushUnsupported`; это ограничение durability, а не доказательство power-loss durability.
