## Offline-продолжение: предыдущие Windows eviction и исследование macOS

Review `24a79d37-da79-4d49-b9be-b26d3c96c568` выявило, что eviction в Windows draft мог удалить первый файл до отказа из-за ACL или числа ссылок следующего файла.
