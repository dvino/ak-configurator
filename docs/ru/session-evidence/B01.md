## Review и ограничения

`b01_pins_review` независимо повторил CAT, проверил размеры и хэши четырёх JSON catalog assets через GitHub API и сверил tag object, commit и успешные CI runs. `b01_reconstruction_review` независимо пересчитал metadata трёх приватных входов и десяти публичных IHX/map pairs, проверил blob официального packer и границы CODE, исследовал скрипт хэширования фактических результатов packer. Packer повторно не запускался. Сырые результаты packer удалены после сохранения metadata. Историческое происхождение приватных входов независимо не подтверждено.

Отдельная загрузка публичного bundle reviewer завершилась `IncompleteRead`; эта попытка не является проверкой bundle побайтно. Идентичность и размер bundle указаны в reconstruction JSON, сам release asset отдельно проверялся при закреплении входов. Приёмка не подразумевает операции с устройством или доказательства установленного образа/физического поведения.

## Следующий этап

Офлайн-реализация QS v3 B02 принята 2026-11-03; см. [evidence B02](B02.md). Авторитетный аудит контракта: [B02-CONTRACT-AUDIT.json](../../session-evidence/B02-CONTRACT-AUDIT.json). В нём указаны запись 24 байта, точный заголовок `51 53 03 11 ff`, CRC-16/CCITT по байтам 0–21 с little-endian хранением в 22–23, QSID 23 по offset 20 как little-endian u16 и image marker 300 для всех десяти проверенных связанных IHX/map профилей. Runtime-поддержка и поведение устройства не квалифицированы.

Аудит также фиксирует разные defaults QSID 22: пустой firmware C default задаёт byte 17 равным 1, официальный Python default vector — 0. Обновление v1 сохраняет byte 17 (в v1 это 0); v2 сохраняет записанное значение. Эти семантики нельзя объединять в реализации или тестах. Приёмка B02 относится только к офлайн evidence реализации; это не runtime- или device qualification.
