## Контракт и ревью

Авторитетный источник wire-схемы и значений firmware: [B02-CONTRACT-AUDIT.json](../../session-evidence/B02-CONTRACT-AUDIT.json). Запись имеет длину 24 байта и заголовок `51 53 03 11 ff`; CRC-16/CCITT охватывает байты 0–21 и хранится little-endian в байтах 22–23. QSID 23 — little-endian `u16` по offset 20. Пустой firmware C default задаёт QSID 22 в byte 17 равным 1; официальный Python v3 default vector задаёт 0. Migration v1 сохраняет byte 17 (в v1 это 0), v2 сохраняет существующее значение. Image marker 300 проверен для всех десяти связанных IHX/map profiles.

Независимый reviewer `b02_code_review` принял офлайн-реализацию без blockers, в том числе после правки wrapper; семантика комбинаций, defaults и запрета downgrade сохранена. V1/V2 model wrapper делегирует общему marker API; для V3 без marker возвращается `Err`. Исправление также добавило regression для parsed byte и явные версии V1/V2 в прежних fixtures. Это static review, без независимого повторного запуска тестов. Итоговый strict Clippy прошёл: `cargo clippy --locked --all-targets --features mcp-mock -- -D warnings` (exit 0).
