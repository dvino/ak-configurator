# B05 — готовность read-only backup UI

English: [EN](../../session-evidence/B05.md).

## Текущий статус

**Офлайн-область read-only backup UI B05 принята 2026-11-03** независимым reviewer `b05_ui_review` после статического review исходника, документации и evidence по сообщённым результатам; повторных запусков reviewer не выполнял, blocking issue не обнаружил. Review охватывает сохранение навигации и error preview, а также typed inspection legacy archives. Обе строгие конфигурации all-target Clippy прошли без issues и suppression. Приёмка не квалифицирует работу live Windows UI, физического устройства, авторизацию ROM, полный workflow Beta5 image или готовность выпуска. Synthetic fixtures проверяют только отображение и не устанавливают доверие к ROM. Проверка физического устройства H01 остаётся незавершённой. Отдельные test-only повторы C01 и его fresh MCP build/STDIO не являются gate B05.

Первая попытка `ak820_backup` завершилась с ошибкой Rust/LLVM «No space left on device» до запуска тестов и не дала результата. Для восстановления удалены 96 файлов пакета (148,6 MiB), затем принадлежащий задаче каталог target перемещён с C: в `D:\codex-ak-configurator-c02-target`. Исторические mock и production binaries сохранены; их хеши проверены: mock — 82 791 936 bytes, SHA256 `b5dea18519146eded7dab0e8b539486a5c4209f2c24271b4f6fd04eb84cf4bd7`; production — 82 789 888 bytes, SHA256 `8122cdf3045e80fab2b93dd4c3d5727b594e35fcb16608f0387f9ee0ace953bb`.

После переноса target компиляция остановилась с Rust E0599: у `egui-kittest` `Node` нет метода `is_disabled`; тесты не запускались. Проверка изменена на `NodeT::accesskit_node().is_disabled`. Изменение UI сохраняет preview при ошибке или отмене `Open`/`OpenManifest`; раньше он очищался в начале открытия. Тесты также проверяют отказ/cancel production `start_file` и stale state, общий для четырёх действий. UI-результаты ниже получены на compiled snapshot без изменений production source B05. Synthetic fixtures проверяют только presentation и не подтверждают доверие к ROM.
